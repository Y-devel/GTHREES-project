# GTHREES — Logistics

Адаптивный корпоративный сайт транспортно-экспедиционной компании на чистых HTML, CSS и JavaScript. Сборщик и npm-зависимости не нужны.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой локальный сервер из корня проекта:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Интерактивность

- Плавная якорная прокрутка и мобильное меню.
- Выбор карточек услуг с hover и клавиатурным фокусом.
- Раскрывающийся FAQ.
- GSAP и ScrollTrigger для появления секций, параллакса и закрепления блоков при прокрутке.
- Шрифты Manrope и Montserrat подключены через Google Fonts.

GSAP и Google Fonts загружаются через CDN, поэтому для их загрузки требуется интернет-соединение.
