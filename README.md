# GTHREES — Logistics

Адаптивный корпоративный сайт транспортно-экспедиционной компании.

## Запуск

```bash
npm install
npm run dev
```

## Технологии

- React + Vite
- GSAP + ScrollTrigger для reveal-анимаций, параллакса и закрепления секций при скролле
- Google Fonts: Manrope и Montserrat

В проекте настроены якорная навигация, плавная прокрутка, hover/selected-состояния карточек услуг, FAQ-аккордеон и форма обратной связи.
